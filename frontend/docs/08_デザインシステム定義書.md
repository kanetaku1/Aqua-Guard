## 02. タイポグラフィ

Inter（日本語は Noto Sans JP）。太さは 400 / 700 のみ。行の高さは文字サイズ×1.4。数値は `tabular-nums`。

| トークン | サイズ / 行高 | 用途 |
| --- | --- | --- |
| `--fs-display` | 24 / 33.6 Bold | KPI値、センサー現在値、状態件数（**数値専用**） |
| `--fs-large` | 20 / 28 Bold | ページタイトル |
| `--fs-medium` | 18 / 25.2 Bold | カード外のセクション見出し、ダイアログタイトル |
| `--fs-normal` | 16 / 22.4 | カードタイトル（Bold）、入力値・ナビ・タブ（Regular） |
| `--fs-small` | 14 / 19.6 | 本文・表のセル（Regular）、ボタン・バッジ・ラベル（Bold） |
| `--fs-helper`（Caption） | 12 / 16.8 | 補足・時刻・Helper text（Regular）、表見出し（Bold） |

1つのカードで使う文字サイズは3段階まで。単位は数値より1段小さくSlate。画面ではALL CAPSを使わない。

## 05. 余白・サイズ・角丸・影

- 余白：`--space-0` 4（部品内部専用）・8・16・24・32・40。12・20・30は使わない。
- **コントロール高さの尺度**：XS 24・S 32・M 40・L 48。

| 部品 | サイズ |
| --- | --- |
| ボタン | S 32・M 40・L 48 |
| 入力欄・Select・サイドナビ項目・表の見出し行 | M 40 |
| 表の行 | L 48（コンパクト M 40） |
| タブ | L 48 |
| セグメント・ページ送り・小ボタン | S 32 |
| 状態バッジ | 28（ページ見出しは32、タイル内は24） |
| タグ（値の種類・参照元）・リンク | XS 24 |
| カード見出し・アラート行 | 最小64 |

- 角丸：4（チェックボックス、ページ送り、タグ）・8（カード、ボタン、入力欄、バッジ、ダイアログ類）。
- 影：カードには付けない。重なって表示されるものにだけ1種類。重なり順：ヘッダー 20・ドロップダウン 30・ダイアログ/ドロワー 50・トースト 60。

## 06. ボタン

4種類：Primary・Outline・Danger・Link（緑の Secondary は v2 で廃止）。

| 種類 | 用途 |
| --- | --- |
| Primary | 1領域に1つ：Submit、Save Record、Acknowledge、Turn On |
| Outline | Cancel、Save Draft、Turn Off、Return to Auto、Clear。ホバー＝Mist背景＋Ink文字（07 §3.1 A2） |
| Danger | 取り消せない・安全に関わる操作の確定。ダイアログ内のみ |
| Link | View、View All →、Detail（Water Blueの文字、XS 24） |

並べ方：最も重要な操作を右、取消をその左。アイコンは16で左側。無効のボタンには理由を示す。

## 07. 入力

M 40、白、1px の Control Border、角丸8、値は16 Regular。ラベルは上（14 Bold、必須は Status Red の `*`）。補足・エラーは下（12）。フォーカス：2px Water Blue＋リング。エラー：2px Status Red＋メッセージ。無効・読み取り専用：Mist。数値欄：単位チップを右端の内側に表示。DBから参照した値：読み取り専用＋参照元タグ。

## 08. 状態表示

| 系統 | 値 | 色 |
| --- | --- | --- |
| 重大度 | Normal < Attention < Warning < Critical | Green / Attention / Orange / Red |
| レポート | Draft → Submitted | Slate / Green |
| アラートの対応状態 | Unacknowledged → Acknowledged → In Progress → Resolved | Red / Slate / Water Blue / Green |
| データ品質 | Live・Delayed・Offline・No data | Green / Yellow / Red / Slate |
| アカウント | Active・Invited・Deactivated | Green / Water Blue / Slate |
| マスタの稼働状態 | Active・Inactive（Farm）/ In operation・Fallow（Pond）/ Online・Offline（機器） | Green / Slate（機器のOfflineは Red） |

アカウント・マスタの状態はすべて Status Indicator で示す（`.st--normal` / `.st--progress` / `.st--neutral`、無効な行は `.is-muted`）。

2つの見せ方（07 §8.2）：

| 部品 | クラス | 使う場面 |
| --- | --- | --- |
| **Status Badge**（面＋枠＋重大度アイコン＋太字、高さ28・lg 32・xs 24） | `.badge .badge--attention / --warning / --critical`（`--lg` / `--xs`） | 対象の重大度が **Attention以上**のときだけ。1つの行・カードに最大1つ。Critical は赤の塗りつぶし・白文字 |
| **Status Indicator**（面・枠なし、点8px＋通常の文字） | `.status-text .st--{state}`（`.status-text--lg`：点10px・16px、ページタイトル横の Normal） | それ以外すべて：Normal、内訳・補助の状態、対応状態（`st--unack` / `st--ack` / `st--progress` / `st--resolved`）、Report状態（`st--draft` / `st--submitted`）、データ品質・設備・アカウント、Status Summary の見出し |

`.badge--normal` / `.badge--draft` / `.badge--submitted` / `.badge--state` は廃止（Indicator に置き換え）。

範囲外の値：`.val-attention` / `.val-warning` / `.val-critical`（文字色＋太字＋重大度アイコン：円 / 三角 / 八角形、07 §8.3）。
