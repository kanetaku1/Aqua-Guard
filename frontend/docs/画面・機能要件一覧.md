# 画面・機能要件書

## Screen & Functional Requirements

## 1. 目的

本書は、業務要件書（BRD）およびユーザー権限定義書（RBAC）に基づき、Smart Shrimp Pond Management Systemに必要な画面と主要機能を定義する。

本書では、各Roleが業務を遂行するために必要な画面・機能のみを定義する。

UIデザイン、詳細なレイアウト、色、フォント、コンポーネント仕様はUI/UX要件書で定義する。

---

# 2. Role

| Role              | 主な管理対象              |
| ----------------- | ------------------------- |
| Farms Manager     | Companyが管理する複数Farm |
| Technical Manager | 担当Farm内のPond          |

# 4. 共通機能

## SCR-COM-001 Authentication

ユーザーは認証後、自身のRoleに応じたシステムへアクセスできる。

## SCR-COM-002 Role-Based Access Control

ユーザーのRoleに応じて、アクセス可能な情報と操作を制御する。

## SCR-COM-003 Data Scope Control

- Farms Manager：Companyが管理する全Farm
- Technical Manager：担当FarmおよびそのFarm内のPond

## SCR-COM-004 Status Display

Farm、Pond、Report等の状態を、業務上必要な範囲で表示する。

# 5. Farms Manager

## 5.1 Dashboard

### 画面の役割

> **Companyが管理するFarmの状態を一覧で把握し、確認が必要なFarmを特定する。**

### 表示情報

- Farm Status
- Farm Risk / Issue
- Production Status
- Pond Anomaly / Trendの概要
- Recent Daily / Weekly Reports

### 主な機能

| ID       | 機能                      | 内容                                   |
| -------- | ------------------------- | -------------------------------------- |
| FM-D-001 | Farm Status Summary       | 各Farmの状態を一覧表示                 |
| FM-D-002 | Risk / Issue Summary      | Farmで確認が必要な問題を表示           |
| FM-D-003 | Production Status Summary | Farmの生産状況を表示                   |
| FM-D-004 | Pond Anomaly Summary      | Farm内Pondの重要な異常・傾向を集約表示 |
| FM-D-005 | Recent Reports            | 最近提出されたReportsを表示            |
| FM-D-006 | Farm Navigation           | 選択したFarmのFarm Detailへ移動        |

# 7. Farms Manager — Farm Detail

## 7.1 Farm Detail

### 画面の役割

> **選択したFarmについて、環境状態・Pond状態・生産状況・Reportsをまとめて確認する。**

Farm DetailはFarms Managerの主要画面とする。

### 情報構成

```text
Farm Detail
│
├── Farm Status
│
├── Pond Status
│   └── Pond Anomaly / Trend
│
├── Production Status
│
├── Risk / Issue
│
└── Recent Reports
```

---

## 7.2 Farm Status

### 役割

Farm全体の現在の状態を把握する。

### 表示情報

- Overall Farm Status
- Environmental Status
- Production Status
- Operational Status
- Status Trend

### 機能

| ID        | 機能                | 内容                 |
| --------- | ------------------- | -------------------- |
| FM-FD-001 | Farm Status Display | Farm全体の状態を表示 |
| FM-FD-002 | Status Trend        | Farm状態の推移を表示 |

---

## 7.3 Pond Status

### 役割

Farm全体の状態を理解するため、Farm内Pondの重要な異常・傾向を確認する。

### 表示情報

- Pond
- Anomaly Type
- Severity
- Trend
- Duration
- Status

### 機能

| ID        | 機能                 | 内容                   |
| --------- | -------------------- | ---------------------- |
| FM-FD-003 | Pond Status Summary  | Pondの状態を集約表示   |
| FM-FD-004 | Pond Anomaly Display | 重要なPond異常を表示   |
| FM-FD-005 | Pond Trend Display   | Pondの異常・傾向を表示 |

### 制約

Farms Managerには以下を表示しない。

- Raw Sensor Data
- 詳細なSensor Time Series
- Actuator Control
- Pondの現場操作機能

# 14. 業務と画面の対応

```text
Farms Manager

Farm状態を把握
        ↓
   Dashboard
        ↓
    Farms
        ↓
   Farm Detail
   ├── Farm Status
   ├── Pond Status
   ├── Production Status
   ├── Risk / Issue
   └── Recent Reports
        ↓
      Reports
```

```text
Technical Manager

Pondを監視
      ↓
  Dashboard
      ↓
    Ponds
      ↓
  Pond Detail
  ├── IoT / Water Quality
  ├── Alerts
  ├── Feeding
  ├── Mortality
  ├── Sampling
  └── Actuator
      ↓
   Reports
```

# 15. 対象外

本画面・機能要件では以下を対象外とする。

- Farm Comparison
- Buyer Matching
- Market Price Simulation
- Sales Management
- Buyer Contract Management
- Revenue Optimization
- International Sales Management
- Transportation / Export Management
- Farms ManagerによるRaw Sensor Monitoring
- Farms ManagerによるActuator操作
- AI Recommendation画面
- Management Decision画面
- AIによる自律的な判断・操作
