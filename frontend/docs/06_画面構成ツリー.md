# 画面構成ツリー（ワイヤーフレーム）

全画面（業務画面・認証画面・管理画面）の構造を「画面 → セクション → 部品 → 状態違い」のツリーで示す。画面の目的・機能IDは「05_画面・機能要件書」、部品の仕様は「08_デザインシステム定義書」を参照する。

- 実装：`frontend/prototype/`（幅1440px）。`index.html` で全画面・状態違いを一覧できる。
- 記法：`[部品名]` は08で定義した共通部品。`〈状態違い〉` はURLパラメータで表示できる状態。
