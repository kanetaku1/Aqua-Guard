# 画面・機能要件書

## Screen & Functional Requirements

## 1. 目的

本書は、01_業務要件書および02_ユーザー権限定義書に基づき、Smart Shrimp Pond Management Systemに必要な**画面、画面遷移、画面ごとの表示内容（優先順）、主要機能**を定義する。

- 各画面の詳細な構造（セクション → 部品 → 状態違い）は「06_画面構成ツリー」
- KPIの算出・集計・閾値は「04_KPI・データ項目定義書」
- 色・サイズ・部品の使い方は「07_UI・UX設計書」「08_デザインシステム定義書」

---

## 2. 画面構成

### 2.1 Role別の画面

```text
Farms Manager                         Technical Manager
├── Dashboard            FM-01        ├── Dashboard              TM-01
├── Farms                             ├── Ponds
│   ├── Farm List        FM-02        │   ├── Pond List          TM-02
│   └── Farm Detail      FM-03        │   └── Pond Detail        TM-03
└── Reports                           │       ├── IoT / Water Quality
    ├── Report List      FM-04        │       ├── Alerts
    │   (Daily / Weekly)              │       ├── Feeding
    ├── Daily Report     FM-05        │       ├── Mortality
    │   Detail                        │       ├── Sampling
    └── Weekly Report    FM-06        │       └── Actuator
        Detail                        └── Reports
                                          ├── Daily Report   TM-04
                                          │   (Create / Edit · History)
                                          └── Weekly Report  TM-05
                                              (Create / Edit · History)
```

サイドバー：Farms Manager は `Dashboard / Farms / Reports`、Technical Manager は `Dashboard / Ponds / Reports`。同じRoleのすべての画面で同じ表示にする。

### 2.3 画面遷移

```text
FM:  Dashboard ─→ Farm Detail ─→ Recent Report ─→ Report Detail
        └─→ Farm List ─→ Farm Detail
     Reports ─→ Report List ─→ Report Detail

TM:  Dashboard ─→ Pond Detail（Pond card / Active Alert から）
        └─→ Pond List ─→ Pond Detail（タブ）
     Reports ─→ Daily / Weekly Report（Create · Edit · Submit · History）
```

- 新しい画面は、必要な情報の粒度または業務タスクが変わるときだけ作る。同じ対象の観点の切り替えはタブで行う（Pond Detail、Report種別）。
- Farm Detail の Pond の異常は、TMが Pond Detail で調査する対象である（役割をまたぐ関係）。FMの画面からTMの画面へのリンクは置かない。
- タブ・絞り込みの状態はURLに保持する。

## 3. 共通機能

| ID | 機能 | 内容 |
| --- | --- | --- |
| SCR-COM-001 | Authentication | 認証後、Roleに応じた画面を表示する |
| SCR-COM-002 | Role-Based Access Control | Roleに応じてアクセスできる情報と操作を制御する。操作権限のない部品は表示しない |
| SCR-COM-003 | Data Scope Control | FM：Company配下の全Farm／TM：担当FarmとそのPond |
| SCR-COM-004 | Status Display | Farm・Pond・Report・Alertの状態を共通の表示体系で示す |
| SCR-COM-005 | Data Freshness | ヘッダーにデータの鮮度（Live / Delayed）と同期時刻（WIB）を表示する |
| SCR-COM-006 | Language | 言語を切り替える（TMはインドネシア語必須、FMはインドネシア語／英語） |

共通レイアウト：Global Header（ブランド・対象範囲・データ鮮度・言語・ユーザー）＋ Role別サイドバー ＋ Page Header ＋ 本文。

## 4. Farms Manager

### FM-01 Dashboard

> **Companyが管理するFarmの状態を把握し、どのFarmを見るべきか判断する。**

| 優先 | セクション | 内容 |
| --- | --- | --- |
| 1 | Farm Status | 状態別のFarm数。Farm一覧表（Farm、Overall、Environmental、Production、Operational、Open Issues、Updated → Farm Detail） |
| 2 | Risk / Issue | 全Farmの未解決のFarm-level Issue（閲覧のみ） |
| 3 | Production Status | 総Biomass（推定・合計）、成長目標より遅れているPond数（全体・Farm別）。平均ABW等の平均値は表示しない |
| 4 | Environmental / Pond Trends | 全Farmの重要な環境の傾向（Farm、Pond、Parameter、Trend、Severity、Duration） |
| 5 | Recent Reports | 全Farmの最新Report |

| ID | 機能 | 内容 |
| --- | --- | --- |
| FM-D-001 | Farm Status Summary | 各Farmの状態を一覧表示 |
| FM-D-002 | Risk / Issue Summary | 確認が必要な問題を表示 |
| FM-D-003 | Production Status Summary | 会社全体で意味を持つ生産の値を表示 |
| FM-D-004 | Pond Anomaly Summary | Pondの重要な異常・傾向を集約表示 |
| FM-D-005 | Recent Reports | 最近提出されたReportを表示 |
| FM-D-006 | Farm Navigation | 選択したFarmのFarm Detailへ移動 |

### TM-03 Pond Detail

> **Pondの環境状態を確認し、必要な技術・運用業務を行う。**

ヘッダー：Pond名、Status、Farm、面積、放養日・DOC、放養尾数・ABW、最終更新。

| タブ | 内容 | ID |
| --- | --- | --- |
| IoT / Water Quality | 6項目の現在値（閾値・センサー状態）、時系列グラフ（項目・期間の切替、閾値の帯）、Anomalies、Historical Data（生データ・ページ送り） | TM-PD-001 Current Sensor Data / 002 Sensor Time Series / 003 Historical Data / 004 Sensor Status / 005 Anomaly Display |
| Alerts | Alert一覧（状態）、Acknowledge、詳細はDrawer（対応状態・メモ） | TM-PD-006 Alert List / 007 Alert Detail / 008 Alert Acknowledge / 009 Alert Status |

| Sampling | 履歴（DOC、ABW、ADG）＋Pondの成長グラフ＋記録フォーム（ABWは自動計算） | TM-PD-016 Record / 017 History / 018 Update |
| Actuator | Safety Layerの注記、機器カード（状態・モード・操作）、自動制御の状態、操作履歴、確認ダイアログ | TM-PD-019 Actuator Status / 020 Actuator Control / 021 Control History |

Actuatorの制約：
- Actuator操作はTechnical Managerのみ許可する。
- Safety Layerの制約に従い、禁止された操作は無効にして理由を示す。
- 自動制御（Auto）中に手動操作すると Manual（override）になることを確認ダイアログで示す。

### TM-04 Daily Report / TM-05 Weekly Report

> **担当FarmのDaily / Weekly Reportを作成・提出する。**

- タブ：Create / Edit と History。
- 入力のセクションは FM-05 / FM-06 と同じ順番・同じ名前にする（TMが提出した内容＝FMが読む内容）。
- DBから参照した値は初期入力し「From sensor data」「From records」を表示する。TMは修正できる。
- 画面下に操作バー（状態・保存時刻、Save Draft、Submit）を固定表示する。Submit は確認ダイアログを通す。
- 状態：Draft → Submitted。提出済みは閲覧のみ。

| ID | 機能 | 内容 |
| --- | --- | --- |
| TM-R-001 / 005 | Report Create | Daily / Weekly Reportを作成 |
| TM-R-002 / 006 | Report Edit | 下書きを編集 |
| TM-R-003 / 007 | Report Submit | Reportを提出 |
| TM-R-004 / 008 | Report History | 過去のReportを確認 |

## 7. 対象外

画面に追加しないもの（要件が変更されない限り）：

- AI Recommendation / AI Insights / Management Decision の画面・カード
- Farm Comparison（Farm間の比較・順位付け）
- Buyer Matching、Buyer Contract、Market Price Simulation、Sales Strategy、Revenue Optimization、International Sales、Transportation / Export
- 収穫推奨日、利益予測、将来在庫（出荷量）予測
- Farms Manager向けの Raw Sensor Monitoring、Actuator操作、Alertの確認・対応、記録の編集
- 平均ABW・平均ADGなど、Pond・Farmをまたいだ単純平均の表示（04_KPI・データ項目定義書 §4）
- 汎用SaaS機能（全体検索、チャット、オンボーディングツアー、アップグレード案内）
- 閾値の設定画面、ユーザー・権限管理画面（別途定義）
