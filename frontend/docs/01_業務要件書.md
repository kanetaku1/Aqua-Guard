# 業務要件書

## Business Requirements Document (BRD)

## 1. 目的

本書は、Smart Shrimp Pond Management Systemにおける業務上の目的、管理対象、Roleごとの責任範囲、および必要な業務を定義する。

本書は「02_ユーザー権限定義書」を基準とする。

画面構成、UI/UX、データベース構造の詳細仕様は本書では定義しない。

---

## 1.1 フロントエンド設計の文書体系

`frontend/docs/` の文書は以下の順に読む。上位の文書が下位の文書の前提になる。

| # | 文書 | 定義すること |
| --- | --- | --- |
| 01 | 業務要件書（本書） | 業務の目的・対象・Roleごとの業務・対象外 |
| 02 | ユーザー権限定義書 | Role・権限・情報アクセス範囲 |
| 03 | 用語定義 | 業務用語・状態・値の種類 |
| 04 | KPI・データ項目定義書 | KPIの計算式と集計ルール、水質項目の単位・閾値、状態の判定ルール |
| 05 | 画面・機能要件書 | 画面構成・遷移・画面ごとの表示内容と機能 |
| 06 | 画面構成ツリー | 全画面の「画面 → セクション → 部品 → 状態違い」の構造（ワイヤーフレーム） |
| 07 | UI・UX設計書 | 色・サイズ・部品を使う判断基準、UXルール、品質基準 |
| 08 | デザインシステム定義書 | 色・書体・アイコン・部品の確定値と実装クラス |

- 文書間で矛盾がある場合は、番号の小さい文書（業務・権限）を正とし、下位の文書を修正する。
- 実装（`frontend/prototype/`）は 05〜08 に従う。仕様を変える場合は文書を先に更新する。
- `en/` は英語版（別途作成）。

## 2. 業務対象

システムでは、以下の階層で養殖業務を管理する。

```text
Company
 ├── Farm A
 │    ├── Pond 01
 │    └── Pond 02
 ├── Farm B
 │    ├── Pond 01
 │    └── Pond 02
 └── Farm C
      ├── Pond 01
      └── Pond 02
```

- **Company**：複数Farmを管理する単位
- **Farm**：複数Pondから構成される養殖管理単位
- **Pond**：エビ養殖を行う現場単位

---

# 3. Roleと業務責任

| Role | 管理単位 | 業務上の姿勢 |
| --- | --- | --- |
| Farms Manager | Company配下の全Farm | 把握する（VIEW / UNDERSTAND） |
| Technical Manager | 担当Farm内のPond | 監視・調査・管理する（MONITOR / INVESTIGATE / MANAGE） |

## 3.1 Farms Manager

Farms Managerは、Companyが管理する複数Farmを対象として、**Farm全体の状態と生産状況を把握し、必要な問題をTechnical Managerへフォローアップする**。

主な業務：

- 複数Farmの状態を把握する
- Farmの環境状態を把握する
- Pondの異常・傾向をFarm全体の状態を理解するために確認する
- Technical Managerから提出されたDaily / Weekly Reportを確認する
- Farm全体のProduction Statusを確認する
- Farmに発生している問題・異常を把握する
- 必要に応じてTechnical Managerへ確認・追加対応を依頼する

Farms Managerは、Pondの現場運用やActuator操作を直接行わない。

---

## 3.2 Technical Manager

Technical Managerは、担当Farm内のPondを対象として、**Pondの環境および日常的な養殖運用を管理する**。

主な業務：

- Pondの環境状態を監視する
- IoTによる水質情報を確認する
- Pond Alertを確認し、必要な対応を行う
- Pondの技術的・運用上の判断を行う
- Feedingを記録・管理する
- Mortalityを記録・管理する
- Samplingを記録・管理する
- 必要に応じてActuatorを操作する
- Daily Reportを作成する
- Weekly Reportを作成する

---

# 4. Farms Managerの業務要件

## BR-FM-001 Farm状態の把握

Farms Managerは、Companyが管理する各Farmの状態を把握できなければならない。

Farm状態は、以下の情報をもとに把握する。

- Farmの環境状態
- Pondの異常・傾向
- Technical ManagerからのReports
- Production Status

Farms ManagerはRaw Sensor Dataを常時監視するのではなく、Farm全体の状態を把握するために必要な情報を確認する。

---

## BR-FM-002 Pond状態の把握

Farms Managerは、Farm全体の状態を理解するため、担当Farm内のPondに発生している重要な異常・傾向を確認できなければならない。

確認対象には以下を含む。

- 異常が発生しているPond
- 異常の種類
- Severity
- 異常の継続状況
- 異常の傾向
- Farm状態への関連情報

Farms ManagerはPondの詳細なセンサー監視や現場対応を行わない。

---

## BR-FM-003 Daily / Weekly Reportの確認

Farms Managerは、Technical Managerが作成したDaily ReportおよびWeekly Reportを確認できなければならない。

Reportsは、Farmの状態およびProduction Statusを把握するための業務情報として利用する。

---

## BR-FM-004 Production Statusの確認

Farms Managerは、各FarmのProduction Statusを確認できなければならない。

Production Statusは、Farm、およびFarmが抱える各Pondのエビの成長具合を把握するために使用する。

主な情報には以下を含む。

- Biomass
- ABW
- ADG
- Survival Rate
- FCR
- 成長目標に対する進み具合（Growth vs target）

Pondごとに放養日が異なるため、生産KPIはPond単位で算出する。Farm・Company単位で表示するのは、合計または重み付きで意味を持つ値に限る（算出・集計ルールは「04_KPI・データ項目定義書」）。

Farms Managerは、Pondごとの生産KPIのサマリー（Pond Production Summary）を閲覧できる。個々の給餌・死亡・サンプリングの記録と、その登録・修正はTechnical Managerの責任範囲とする。

---

## BR-FM-005 Farm Risk / Issueの把握

Farms Managerは、Farm全体として管理上注意が必要な問題・異常を把握できなければならない。

Risk / Issueには、例えば以下を含む。

- 継続する環境上の問題
- 複数Pondに関連する問題
- 生産状況に影響する問題
- Technical Managerから報告された重要な問題

Risk / Issueは、単一のPond Alertそのものではなく、Farm全体の管理上確認する必要がある問題を対象とする。

---

## BR-FM-006 Technical ManagerへのFollow-up

Farms Managerは、Farmの状態やReportsを確認した結果、必要に応じてTechnical Managerへ確認・追加対応を依頼できなければならない。

Follow-upの例：

- 状況の追加確認を依頼する
- 詳細な報告を依頼する
- 継続的な監視を依頼する
- 発生している問題について確認する

Farms Manager自身がPondの技術的操作を行うことはない。

---

# 5. Technical Managerの業務要件

## BR-TM-001 Pond環境監視

Technical Managerは、担当Farm内のPondの環境状態を監視できなければならない。

対象となるIoT情報：

- DO
- pH
- Water Temperature
- TDS
- Turbidity
- Water Level

---

## BR-TM-002 Pond Alert対応

Technical Managerは、Pondで発生したAlertを確認し、必要な技術的・運用上の対応を行う。

---

## BR-TM-003 Pond運用管理

Technical Managerは、日常的な養殖運用に関する情報を管理する。

対象：

- Feeding
- Mortality
- Sampling

---

## BR-TM-004 Actuator管理

Technical Managerは、必要に応じてPondのActuatorを操作する。

Actuator操作はTechnical Managerの責任範囲とする。

---

## BR-TM-005 Daily Report

Technical Managerは、担当FarmのDaily Reportを作成し、Farmの環境・運用状況を報告する。

---

## BR-TM-006 Weekly Report

Technical Managerは、担当FarmのWeekly Reportを作成し、Farmの環境・運用状況および生産状況を報告する。

---

# 7. 業務責任の境界

| 業務                       | Farms Manager  | Technical Manager |
| -------------------------- | -------------- | ----------------- |
| Farm全体の状態把握         | ●              | ○                 |
| Pond環境監視               | ○ 集約情報のみ | ●                 |
| Raw Sensor Data確認        | -              | ●                 |
| Pond Alert対応             | -              | ●                 |
| Feeding管理                | -              | ●                 |
| Mortality管理              | -              | ●                 |
| Sampling管理               | -              | ●                 |
| Actuator操作               | -              | ●                 |
| Daily Report               | View           | Create            |
| Weekly Report              | View           | Create            |
| Farm Production Status     | ●              | ○                 |
| Pond Production Summary（Pond別の生産KPI） | View | Manage |
| Farm Risk / Issue          | ●              | ○                 |
| Technical Follow-up        | ●              | -                 |

`●`：主担当
`○`：参照・補助
`-`：対象外

# 9. 対象外

現時点では以下を業務要件の対象外とする。

- Buyer Matching
- Market Price Simulation
- Sales Strategy
- Buyer Contract Management
- Revenue Optimization
- International Sales Management
- Transportation / Export Management
- Farms ManagerによるRaw Sensor Monitoring
- Farms ManagerによるPondの技術的操作
- Farms ManagerによるActuator操作
- Farms ManagerによるPond Alertの確認・対応（Acknowledge / Resolve）
- Farm間の比較・順位付け（Farm Comparison）
- AI Recommendation / AI Insights / AIによるManagement Decision
- 収穫推奨日・利益予測・将来在庫（出荷量）予測
